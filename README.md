# jindalyash07.github.io

Personal portfolio of Yash Jindal, served by GitHub Pages at https://jindalyash07.github.io.

Plain HTML, CSS and a little JavaScript, with no build step. Edit `index.html`, push, and the site updates in about a minute.

- `index.html`: all the content
- `style.css`: the graph-paper notebook theme (light and dark)
- `plot.js`: the hero chart; update the `TIMER` and `FUSION` arrays when PanSense's results change
- `resume.pdf`: the résumé linked from the page
